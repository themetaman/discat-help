# DisCat 🐱 — Help & User Guides

**DisCat** is a desktop manager for your [Discogs](https://www.discogs.com/) record
collection. It downloads your collection, enriches it with purchase history, market
values and per-track key/energy data, organises folders, syncs custom fields, and
ships with a localhost web companion plus a Claude Desktop (MCP) integration.

This repository hosts the **user guides** for DisCat. (The application source lives
in a separate repository.)

## 📖 Guides

- **[DisCat User Guide](DISCAT_USER_GUIDE.md)** — how to use every feature of the
  desktop app: downloading your collection, organising folders, custom fields,
  wantlist scanning, market values, stats, the web companion and more.
- **[MCP / Claude Desktop Guide](DISCAT_MCP_USER_GUIDE.md)** — how to query and
  manage your collection from Claude Desktop using the DisCat MCP server.

## ✨ Highlights

- Full collection download with smart caching and safe re-downloads
- Complete purchase metadata — price, seller, condition, clickable order links
- Automatic folder organisation by genre / style
- Custom-field sync to Discogs
- Wantlist seller-coverage scanning and condition-aware fair-value readouts
- Market values (sales history with a listings fallback)
- Localhost read-only web companion — collection, wantlist, stats, market,
  purchases and playlists
- Claude Desktop integration via the MCP server
